# SalesPulse - Sales Analytics Dashboard

A modern, high-performance sales analytics dashboard built with vanilla HTML, CSS, and JavaScript.

## Features
- **Key Performance Indicators (KPIs)**: Gross revenue, net profit margin, total transactions, units sold, AOV, and refund rate.
- **Interactive Visualizations**: Custom high-DPI HTML5 Canvas charts with responsive hover tooltips for revenue/profit trajectory, category distribution, acquisition channels, and regional performance.
- **WebStorage Persistence**: Full client-side persistence via `localStorage` with record tracking and storage capacity indicators.
- **Transaction Ledger**: Searchable, filterable, and paginated table with real-time deletion and CSV export.
- **Sales Entry Modal**: Add new verified transactions with instant metric recalculation.
- **Zero CSS Variables**: Built completely with standard, explicit CSS values.
- **Offline & Zero Dependencies**: No frameworks, no external libraries, no backend required.

## Quick Start
Open `index.html` in any modern web browser.
